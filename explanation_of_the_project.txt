=== PROJECT CONTEXT ===

Product: Pillars of Creation: Spectral Explorer 3D
Type: Interactive 3D web app (localhost → Vercel)
Inspiration: Solar System Scope (solarsystemscope.com) — same fluid, 
finger-driven 3D navigation feel.

What we are building:
A browser-based 3D experience of the Pillars of Creation (Eagle Nebula, M16).
The user can freely orbit, zoom, and explore the Pillars in 3D using mouse 
or touch (pinch/rotate). The scene shows three volumetric gas-and-dust pillar 
structures surrounded by a deep-space star field. A spectral toggle switches 
the entire scene between Hubble visible-light (blue-green palette) and Webb 
near-infrared (orange-red palette), revealing hidden protostars only visible 
in IR mode. Clicking a pillar opens a science info panel.

What we are NOT building (MVP scope):
- No analytics, no accessibility features, no guided tours, no gamification
- No real FITS data yet — shapes and colors are scientifically approximated
- No backend, no user accounts, no mobile app

North Star Metric: Sessions where a user completes at least one spectral 
toggle AND spends 30+ seconds interacting with a pillar region.

Tech stack: React 18, Vite, Three.js, GLSL shaders via vite-plugin-glsl.
Developers: Aidar (19, leads architecture + shaders) and Akmatbek (14, 
handles UI components, hotspot content, testing).
Hardware: M3 MacBook Air 13-inch.

Code rules:
- No generic or AI-clichéd variable names
- Comments only where logic is genuinely complex
- Efficient, clean, minimal — no over-engineering
- Every file should know its single responsibility
